# Datheon_Python_Programming_Internship

Python Programming Internship Projects

This repository contains my Python projects completed as part of the Datheon Python Programming Internship.

## Task 1: Hangman Word Guessing Game

A Python-based word guessing game in which the player guesses a hidden word one letter at a time.

**Features:**
- Random word selection
- Displays hidden letters using underscores
- ASCII art for incorrect guesses
- Tracks incorrect guesses
- Displays win or game-over messages

**Technology:** Python 3

**Run the program:**
```bash
python hangman.py
```

## Task 2: Stock Portfolio Performance Tracker

A Python program that calculates stock investment values and tracks profit or loss for each holding.

**Features:**
- Accepts stock ticker symbols, buying prices, and quantities
- Uses sample stock prices for calculations
- Calculates total investment and current portfolio value
- Calculates gain or loss and its percentage
- Exports the portfolio summary to a CSV file

**Files:**
- `portfolio.py` — Main Python program
- `portfolio_summary.csv` — Generated portfolio summary

**Technology:** Python 3, `csv`

**Run the program:**
```bash
python portfolio.py
```

**Note:** The program uses sample prices, not live stock market data.

## Task 4: Rule-Based Customer Support Chatbot

An interactive terminal chatbot that responds to customer questions using predefined rules and regular expressions.

**Features:**
- Recognizes user intents using regex patterns
- Handles multiple intents in a single message
- Answers questions about business hours, products, delivery, returns, and payments
- Provides fallback responses for unrecognized queries
- Supports `bye`, `exit`, and `quit` commands
- Tracks conversation state and message history
- Handles empty input and interruptions

**Technology:** Python 3, `re`

**Run the program:**
```bash
python chatbot.py
```
