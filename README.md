# Datheon Python Programming Internship

Python Programming Internship Projects

## Task 1: Hangman Word Guessing Game
A Python-based word guessing game using random word selection and ASCII art.

**Features:**
- Random word selection
- Tracks incorrect guesses
- Displays win or game-over messages

**Run:**
`python hangman.py`

## Task 2: Stock Portfolio Performance Tracker
A Python program that calculates investment value and profit or loss for stock holdings.

**Features:**
- Accepts stock ticker, buy price, and quantity
- Calculates total investment and current value
- Calculates gain or loss percentage
- Exports the portfolio summary to a CSV file

**Files:** `portfolio.py`, `portfolio_summary.csv`

**Run:**
`python portfolio.py`

## Task 4: Rule-Based Customer Support Chatbot
An interactive terminal chatbot that responds to common customer questions using predefined rules and regular expressions.

**Features:**
- Recognizes multiple intents
- Answers questions about business hours, prices, delivery, returns, and payments
- Handles unknown queries with fallback responses
- Supports exit commands
- Tracks conversation state and history

**Run:**
`python chatbot.py`
